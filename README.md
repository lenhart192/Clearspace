# Clearspace

A quiet focus timer for Base. Complete a real session, preserve the result onchain, and maintain a separate daily return streak.

## Actions

- `completeSession(uint16 minutesAmount)` records one completed focus session.
- `dailyCheckIn()` maintains the daily streak.
- No token, stake, payment, or app fee. Users only pay Base network gas.

See `DEPLOY.md` for Remix and Netlify instructions.
